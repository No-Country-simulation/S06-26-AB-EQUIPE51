# App BiT - Planejamento Oficial do Hackathon

## Objetivo Final

Criar uma plataforma de recrutamento inclusivo para empresas com metas ESG que permita:

- Publicação de vagas
- Matching inteligente de candidatos
- Mapa de concentração de talentos
- Dashboard ESG
- Deploy online para demonstração
