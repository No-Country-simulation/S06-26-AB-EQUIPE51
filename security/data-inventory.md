# Inventário de Dados

## Dados de Empresas

| Campo               | Classificação |
| ------------------- | ------------- |
| Nome da Empresa     | Público       |
| Meta ESG            | Interno       |
| Grupos Prioritários | Sensível      |

## Dados de Usuários

| Campo | Classificação |
| ----- | ------------- |
| Nome  | Pessoal       |
| Email | Pessoal       |
| Senha | Crítico       |

## Dados de Candidatos

| Campo                | Classificação |
| -------------------- | ------------- |
| Nome                 | Pessoal       |
| Localização          | Pessoal       |
| Grupo de Diversidade | Sensível      |
| Currículo            | Sensível      |

## Observações

Os dados classificados como Sensíveis ou Críticos exigem controles adicionais de segurança, autenticação e autorização.
