# LGPD e Privacidade

## Finalidade dos Dados

Os dados coletados serão utilizados exclusivamente para processos de recrutamento e seleção.

## Consentimento

O candidato deverá concordar com o tratamento dos dados antes do cadastro.

## Minimização de Dados

A plataforma deve coletar apenas os dados necessários para o processo seletivo.

## Exclusão

O usuário poderá solicitar a exclusão de seus dados.

## Proteção

Os dados deverão ser protegidos por mecanismos de autenticação, autorização e criptografia de credenciais.
